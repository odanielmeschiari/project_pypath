# ROTEIRO DO PROJETO PYPATH
Projeto de História da Computação 2026.

1 - MÁQUINA DO TEMPO

Você é um jovem cientista que acabou de entrar no seu laboratório. Há anos você tenta fazer sua máquina do tempo funcionar… mas nunca deu certo. Hoje parece diferente porque depois de muitos testes, você finalmente acredita ter encontrado a peça que faltava. Com o coração acelerado, você encaixa a peça na máquina.
(Um barulho alto ecoa pelo laboratório e uma luz intensa toma conta da sala)
Quando tudo volta ao normal, a máquina está funcionando. Seu grande sonho se tornou realidade: agora você pode viajar no tempo para conhecer as maiores mentes da história da computação. Ajuste as coordenadas temporais… Sua primeira aventura vai começar!!


2 -  ALGORITMOS 

Você sai da máquina e percebe que está em um antigo escritório cheio de papéis e engrenagens. Uma mulher observa anotações ao lado de um projeto de máquina. Você se aproxima e ela se apresenta:
Ada Lovelace: Olá! Você está no século XIX. Sou Ada Lovelace e trabalho com ideias para uma máquina criada por Charles Babbage chamada Máquina Analítica. 
(Essas instruções são consideradas por muitos historiadores o primeiro algoritmo feito para ser executado por uma máquina)
Ada Lovelace: Você sabe o que são algoritmos? Resumidamente são uma sequência clara de passos para resolver um problema. Algoritmos existem há muito tempo: matemáticos antigos já criavam sequências de passos para resolver problemas, como fazer contas ou encontrar padrões em números. 
Ada Lovelace: Sabendo disso eu gostaria que você me ajudasse organizando pequenas instruções para realizar uma operação matemática, seria de grande ajuda!
Organize os papéis na ordem correta para formar um algoritmo que calcule a soma de dois números:
1- Selecione o primeiro número
2- Selecione o segundo número 
3- Some os dois números 
4- Anote o resultado
5- Mostre o resultado
