Nosso projeto é um jogo (escrito com as linguagens HTML, CSS e JS) que conduz o jogador através de uma narrativa interativa. A mecânica básica do jogo consiste em interações com NPCs (que também são pessoas importantes na História da Computação, como Ada Lovelace e Alan Turing), nas quais o usuário aprende, ao mesmo tempo, conhecimentos da História Geral da Computação e programação básica em linguagem Python, com teoria e exercícios aplicados. No site, colocamos tanto o link de acesso para o jogo quanto uma seção com as biografias de todas as figuras históricas que aparecem durante a gameplay.
